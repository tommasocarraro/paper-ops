# Venue templates

Put each venue's LaTeX author kit here, one folder or `.zip` per template:

```
venue-templates/
  acm-sigconf/        ← unzipped kit from the venue or Overleaf ("Download source")
  lncs.zip
```

Then run `/paper-ops template acm-sigconf` to install it into the active paper. A kit stays here and can be reused for later papers.
