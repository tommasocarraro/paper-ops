# Writing samples

Put papers here that you wrote yourself, without AI assistance. The `style` mode reads them to build `voice-dna.md`.

- `.tex` sources are best: they also show your LaTeX and notation habits. PDF, `.md` and `.txt` work too.
- Three or more papers give a reliable profile. One is enough to start.
- Co-authored papers are fine. `style` will ask which sections you wrote.
- Theses, technical reports and long blog posts count if they sound like you.

After adding samples, run `/paper-ops style`.
